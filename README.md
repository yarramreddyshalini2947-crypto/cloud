# Cloud Management System

## Project Description
The Cloud Management System is a web-based application designed to manage cloud resources efficiently. The system allows administrators to manage virtual machines, storage, networks, resource allocation, billing, and usage monitoring. Users can register, log in, request resources, view allocations, monitor usage, and check billing information.

The system provides an organized platform to manage cloud infrastructure and ensures better resource utilization.

---

## Features

### Admin Features
- Admin login
- Manage Virtual Machines
- Manage Storage
- Manage Network
- Manage Billing
- Manage Users
- View Resource Requests
- Allocate Resources
- Monitor Resource Usage

### User Features
- User Registration
- User Login
- Request Cloud Resources
- View Resource Allocation
- Monitor Usage
- View Billing Details
- Logout
